# mcp-a11y-demo

**Controlled** demonstration target for
[**mcp-a11y**](https://github.com/P4ST4S/mcp-a11y) — the MCP server for web
accessibility remediation.

This repository contains nothing but **one intentionally broken page**. It
exists to exercise the full mcp-a11y pipeline end-to-end, under real
conditions:

1. **`audit_page`** detects WCAG violations on the public URL (axe-core,
   deterministic).
2. **`fix_contrast`** + **`simple_fixes`** + **`generate_alt_text`** produce
   deterministic fixes (colors reinjected by CSS selector, the `alt` text
   generated by a real vision call against the image hosted here).
3. **`open_pr`** opens a PR on **this repository** with the fixed page.

> ⚠️ The [`index.html`](index.html) page is **intentionally inaccessible**.
> That's the point. The post-remediation "after" state must drop back to
> **zero violations**.

## Audited page

| | |
|---|---|
| **GitHub Pages (default branch)** | https://p4st4s.github.io/mcp-a11y-demo/ |
| **Raw `index.html` (to re-audit a PR branch)** | `https://raw.githubusercontent.com/P4ST4S/mcp-a11y-demo/<branch>/index.html` |
| **Hero image (prerequisite of the real vision call)** | https://raw.githubusercontent.com/P4ST4S/mcp-a11y-demo/main/assets/hero.png |

To **verify a PR branch**, audit the `raw.githubusercontent.com` URL of the
branch: it's instant, with none of the GitHub Pages rebuild latency. GitHub
Pages only serves the default branch.

## Injected violations

Exactly the five axe rules mcp-a11y can fix — nothing else, so the "after"
state drops to zero:

| axe rule | Trigger in the page |
|---|---|
| `html-has-lang` | `<html>` with no `lang` attribute |
| `document-title` | no `<title>` in the `<head>` |
| `image-alt` | 2 `<img>` with no `alt` attribute |
| `color-contrast` | 3 text/background pairs below the AA 4.5:1 ratio — `#777777` on `#ffffff` (4.48:1), `#5a8fd6` on `#ffffff` (3.32:1), `#ffffff` on `#6cb2eb` (2.28:1) |
| `label` | 2 form fields with no associated `<label>` |

## Structural invariants (DO NOT MODIFY)

mcp-a11y reinjects its fixes **by CSS selector**, not by value. Its glue only
works if the rendered DOM is strictly identical to the source. Therefore:

- **100% static, ZERO JavaScript** — the rendered DOM must be identical to the
  source file, otherwise the fixes won't remap.
- **All colors in a SINGLE `<style>` block** in the `<head>`, via simple
  classes. No external CSS, no inline styles, no complex cascade.

Any added JS, external CSS, or inline styles **breaks reinjection**.
